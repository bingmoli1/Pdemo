## 多账号切换器（浏览器扩展 v1.0.0）
- 需求：通用任意网站、多账号登录态一键切换；用户选择浏览器扩展形态（非 Tkinter 桌面端）。
- 实现：Manifest V3 扩展，核心是通过 `chrome.cookies` 对当前 hostname 及其父域做 Cookie 快照/清除/恢复，数据存 `chrome.storage.local`。
- 文件：`manifest.json`、`background.js`、`popup.html`、`popup.css`、`popup.js`、`icons/icon{16,48,128}.png`（Python 标准库 zlib 生成，无第三方依赖）。
- 功能：保存当前登录为新账号、一键切换、覆盖保存、编辑名称/备注、删除、自动保存开关、JSON 导入导出备份、切换后自动刷新该域名标签页。
- 交付：`多账号切换器-扩展.zip`（Chrome/Edge 开发者模式「加载已解压的扩展程序」使用）。
- 验证：node --check 两处 JS 通过；manifest JSON 与文件引用校验通过；Node vm + mock chrome API 模拟测试通过（域名层级含 co.uk 公共后缀、切换恢复 2/2、自动保存旧账号生效）。

## v1.0.4 修复「保存后退出登录，切不回登录态」
- 根因1（交互）：当前账号原本只有「刷新保存」按钮，点它会用当前空 Cookie 覆盖快照，导致再也切不回登录态。改为所有账号（含当前账号）主按钮都是「切换」= 重新写入该账号快照的 Cookie；「覆盖保存」降级为 ⟳ 小图标按钮。

- 空状态防护：addAccount / overwriteAccount 在检测到 0 项 Cookie 时直接报错拒绝，避免保存空快照。
