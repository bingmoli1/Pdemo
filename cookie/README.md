# 网站登录管理器（浏览器版）

主程序是 `main.py`：一个网站列表式的登录管理工具。每个网站登录一次，之后打开即可直接登录。

**没有独立窗口**——双击 `打开网站列表.bat` 后自动在浏览器中打开管理页面，所有操作都在网页上完成。

## 功能

1. **网站列表**：页面显示所有添加的网站及登录状态，每 2 秒自动刷新
2. **新增网站**：点击「➕ 新增网站」，填写网站地址即可加入列表
3. **登录并记录状态**：点「🔑 登录并记录状态」会弹出该网站专用的浏览器窗口，手动完成登录后**关闭该浏览器窗口**，状态自动记录
4. **打开网站（直接登录）**：点「🚀 打开」，使用已记录的登录状态打开，无需再次登录
5. **清除登录状态 / 删除网站**：每行有对应按钮
6. **退出程序**：点右上角「退出程序」结束本地服务

## 运行

**双击 `打开网站列表.bat`**——自动启动本地服务（不弹黑色命令行窗口）并打开浏览器管理页面 `http://127.0.0.1:8317`。

也可以用命令运行：

```bash
python main.py
```

主程序**仅使用 Python 标准库**，无需安装任何第三方依赖（Python 3.8+ 即可）。

重复双击 bat 不会启动第二个实例，只会再打开一个管理页面。

## 原理说明

程序在本机自动查找 Chrome 或 Edge 浏览器，为每个网站创建独立的浏览器配置目录：

```
profiles/
  github.com/        # github.com 专用浏览器配置（保存登录状态）
  www.bilibili.com/
```

登录状态（Cookie、localStorage、会话等）完整保存在配置目录中，因此比单纯复制 Cookie 更可靠，也能正常处理 JS 渲染、验证码、扫码登录等场景。

管理页面由本机 `127.0.0.1` 上的小服务提供，只监听本机回环地址，且接口带随机令牌校验，外部网页无法调用。

## 文件说明

- `打开网站列表.bat`: 双击启动并打开浏览器管理页面
- `main.py`: 主程序（本地服务 + 网页）
- `sites.json`: 网站列表数据（程序自动生成）
- `profiles/`: 各网站的浏览器配置目录，**包含登录凭据，请勿泄露、勿提交到 git**
- `cookie_manager.py` / `cookie_manager_advanced.py` / `cookie_manager_browser.py`: 早期版本（基于 requests / Selenium 抓取 Cookie），仅供参考
- `requirements.txt`: 早期版本的依赖，主程序不需要

## 注意事项

1. **安全提示**：`profiles/` 目录中保存了各网站的完整登录凭据，请妥善保管，不要泄露给他人
2. **登录有效期**：网站登录态过期后（Cookie 失效），重新点一次「登录并记录状态」即可
3. **退出**：直接关掉页面标签服务仍会运行，请点页面右上角「退出程序」结束服务；下次双击 bat 会自动重新打开页面
4. **合法使用**：请仅用于自己的账号和合法用途，遵守网站服务条款
