功能

> **程序只有一个窗口**：启动即进入「批量转码」主界面（窗口标题「二维码工具 - 批量转码」），直接以根窗口运行，不再有隐藏主窗口。单张互转页面及其切换按钮已移除；关闭窗口即退出程序。

- `文本 → 二维码`（批量生成）：一行一条内容，支持「导入 TXT/CSV」对话框**一次多选**多个清单文件（内容按选择顺序合并，单个文件失败不影响其余）、粘贴、直接拖入多个清单文件；可设输出目录、命名方式（序号/内容）、前缀、起始序号；批量生成 PNG（UTF-8 字节写入、H 级纠错），已存在的同名文件自动加后缀不覆盖。生成中显示进度、可取消，结果可导出 CSV/TXT 清单。
- `二维码 → 文本`（批量识别）：可多选图片、添加文件夹、或直接拖入图片/文件夹；**「包含子文件夹」默认勾选**，添加的文件夹连同下级目录一起扫描（只需扫当前层可手动取消勾选）；一张图里有多个二维码会全部读出；逐张显示识别结果与状态，可一键复制全部结果、导出 CSV（带 BOM，Excel 直接打开）或 TXT。
- 默认输出目录为 `桌面/二维码批量输出`，可随时改；把 TXT/CSV 清单、二维码图片或文件夹拖入窗口，会自动分派到对应页签。
- 编解码统一由模块级 `make_qr_image` / `decode_qr_image` / `smart_decode` 实现，批量生成与批量识别结果一致。

打包

> 当前构建配置（`二维码工具.spec`）已锁定为：**不压缩（upx=False）、不排除任何模块**，重新打包会得到与现版 `二维码工具.exe`（约 22.5 MB）功能等价的产物。

方式一：直接用命令行（与 `二维码工具.spec` 等价）
```bash
pyinstaller --noconfirm --noupx -F -w --name "二维码工具" --icon qr_icon.ico --distpath . --collect-all pyzbar qr_gui.pyw
```

方式二：用已固化的 spec 文件（推荐，配置写在 `.spec` 里）
```bash
pyinstaller --noconfirm --distpath . 二维码工具.spec
```

说明：
- `-F` 单文件、`-w` 窗口模式、`--icon qr_icon.ico` 内嵌图标、`--collect-all pyzbar` 收集解码所需的 zbar DLL。
- `--noupx` 对应 `.spec` 中的 `upx=False`，确保不被意外压缩（功能不变，体积保持原始大小）。
- 依赖装在系统 Python 3.14（`C:/Users/12416/AppData/Local/Programs/Python/Python314/python.exe`），PATH 上的 3.13 无依赖；需安装 `qrcode`、`pyzbar`、`Pillow(PIL)`、`tkinterdnd2`、`PyInstaller`。
- 产物 `二维码工具.exe` 为自包含单文件，复制到任意 Windows 64 位电脑双击即可运行，无需安装运行库。
