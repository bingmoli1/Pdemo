把快捷方式放在启动文件夹自启动

功能

> **程序只有一个窗口**：启动即进入「批量转码」主界面（窗口标题「二维码工具」），直接以根窗口运行，不再有隐藏主窗口。单张互转页面及其切换按钮已移除；关闭窗口即退出程序。

- `文本 → 二维码`（批量生成）：一行一条内容，支持「导入文件」对话框**一次多选**多个清单文件（内容按选择顺序合并，单个文件失败不影响其余）、粘贴、直接拖入多个清单文件；可设输出目录、命名方式（**默认「内容命名」**，可切「序号命名」）、前缀（**默认为空**）、起始序号；批量生成 PNG（UTF-8 字节写入、H 级纠错），已存在的同名文件自动加后缀不覆盖。生成中显示进度、可取消，结果在右侧表格逐条显示（生成页不提供导出）。
- 清单格式：`TXT` / `CSV` / `TSV` / Excel `.xlsx` / Word `.docx` 都能直接导入或拖入，只用标准库解析（无需安装 Office、openpyxl 或 python-docx）。**Word 按每行一条**（正文段落一行，段落内手动换行再拆行；表格每行取第一个单元格）；**Excel 读取所有单元格**（按行优先，每一个非空方框 = 一条，包含第二列及之后的内容；表头整行跳过）；**CSV / TSV 仍取每行第一个非空单元格**。以上均空行忽略，Excel 目前只读第一个工作表。旧版 `.xls` / `.doc` 需先另存为新格式或 CSV。
- `二维码 → 文本`（批量识别）：可多选图片、添加文件夹、或直接拖入图片/文件夹；**「包含子文件夹」默认勾选**，添加的文件夹连同下级目录一起扫描（只需扫当前层可手动取消勾选）；一张图里有多个二维码会全部读出；逐张显示识别结果与状态，可一键复制全部结果，或导出 CSV / TXT / Excel `.xlsx` / Word `.docx` 四种格式（保存对话框选中的「保存类型」决定格式，文件名扩展名会自动修正，导出完成会提示实际格式）。**Word / TXT 只导出识别内容，一行一条**（与「复制全部结果」一致：跳过未识别的条目，条目内换行压成空格；导出的文件可直接拖回工具再生成二维码）；**CSV / Excel 仍导出「序号 / 文件名 / 状态 / 识别结果」四列表格**（CSV 带 BOM，Excel 为单工作表）。均用标准库生成，无需安装 Office。
- 默认输出目录为 `桌面/二维码批量输出`，可随时改；把清单文件（TXT/CSV/Excel/Word）、二维码图片或文件夹拖入窗口，会自动分派到对应页签。
- **记住上次设置**：输出目录、命名方式、前缀、起始序号、「包含子文件夹」、上次导出格式、当前页签会自动保存到 `%APPDATA%\二维码工具\settings.json`。文件是纯文本 JSON，可直接查看 / 修改 / 删除（删掉即恢复出厂默认）；只记界面设置，不记输入清单和识别结果。改动后 400ms 内自动落盘，关闭窗口时再兜底保存一次；放在用户目录，项目目录不会多出文件。换电脑或新用户首次运行仍用默认值，配置不跟着 exe 走。
- 编解码统一由模块级 `make_qr_image` / `decode_qr_image` / `smart_decode` 实现，批量生成与批量识别结果一致。

打包

> 当前构建配置（`二维码工具.spec`）已锁定为：**不压缩（upx=False）、不排除任何模块**，重新打包会得到与现版 `二维码工具.exe`（约 22.5 MB）功能等价的产物。

方式一：直接用命令行（与 `二维码工具.spec` 等价）
```bash
pyinstaller --noconfirm --noupx -F -w --name "二维码工具" --icon qr_icon.ico --distpath . --collect-all pyzbar qr_gui.pyw
```

方式二：用已固化的 spec 文件（推荐，配置写在 `.spec` 里）
```bash
pyinstaller --noconfirm --distpath . 二维码工具.spec
```

说明：
- `-F` 单文件、`-w` 窗口模式、`--icon qr_icon.ico` 内嵌图标、`--collect-all pyzbar` 收集解码所需的 zbar DLL。
- `--noupx` 对应 `.spec` 中的 `upx=False`，确保不被意外压缩（功能不变，体积保持原始大小）。
- 依赖装在系统 Python 3.14（`C:/Users/12416/AppData/Local/Programs/Python/Python314/python.exe`），PATH 上的 3.13 无依赖；需安装 `qrcode`、`pyzbar`、`Pillow(PIL)`、`tkinterdnd2`、`PyInstaller`。Excel/Word 清单**解析**用标准库 `zipfile` + `xml.etree`，Excel/Word 结果**导出**用标准库手写 OOXML（`zipfile` + `xml.sax.saxutils`），都不增加打包依赖。
- 产物 `二维码工具.exe` 为自包含单文件，复制到任意 Windows 64 位电脑双击即可运行，无需安装运行库。
