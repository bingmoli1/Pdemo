打包

双击 `build.bat` 即可；或在本目录打开 Git Bash 执行下面这条命令（全文只此一条）：

```bash
(taskkill /F /IM "二维码工具.exe" 2>/dev/null || true) && py -m pip install --disable-pip-version-check -q pyinstaller qrcode pyzbar pillow tkinterdnd2 && py -m PyInstaller --noconfirm --distpath . "二维码工具.spec"
```

- 整个项目文件夹拷到任意电脑、任意位置都能直接打包：`build.bat` 用 `%~dp0` 自定位，命令不含绝对路径；都用不带版本号的 `py` 并自动 `pip install` 依赖，换 Python 版本也能构建。
- 新电脑只需装一个较新的 Python 3（勾选 py launcher），首次联网装依赖约 10 MB；没装 Python 或缺依赖时脚本会给出提示。
- 必须走 `二维码工具.spec`（单文件 + `collect_all('pyzbar')`）。**不要**换成纯参数命令，漏掉 zbar 会让新机器上「二维码 → 文本」失效。
- 产物 `二维码工具.exe` 自包含：拷单个文件即可在 Win10/11 x64 运行，无需 Python / Office / VC++、不联网；首次运行可能被 SmartScreen 拦，选「仍要运行」。别只拷 `.lnk` 快捷方式。

功能

> 启动即进入批量转码主界面，关闭窗口即退出。

- **文本 → 二维码**：一行一条内容，可导入 / 拖入多个 TXT、CSV、TSV、Excel、Word 清单，或直接粘贴。命名方式（默认「内容命名」）、前缀（默认空）、起始序号在「更多设置」里；点「开始生成」只在内存中生成二维码（**不写文件**），点旁边的「导出」会**先弹出目录选择框让你选导出位置**，确认后才把 PNG 写进去（下次选择框默认停在上次位置）；「导出」按钮始终可点，可反复导出到不同位置，同名自动加后缀不覆盖；**改了配色或宽高后不用重新生成，点「导出」会先按当前设置把内存里的图重画一遍再写盘**（双击结果行复制图片也取当前设置）；导出前也能双击结果行复制图片。命名、前缀、起始序号、图片宽高收在「更多设置」弹窗里（按钮显示 / 再点收起，改动自动记住）；宽高默认 300 × 300 px（范围 100–4000），输出严格为该宽高；「更多设置」里还能改**前景色 / 背景色**（默认黑块白底，点色块弹出取色器（拖动色相条与饱和度/明度方块取色，也可直接填色值），也可手输 `#RRGGBB` 或 `#RGB` 简写，两色相同时拒绝生成）；**二维码方块区域**占较短边 **90%**（边缘不计入这 90%，四周只留 5%）、等比居中不拉伸，内容长到每模块不足 2 像素时保持 1 像素/模块原样居中（占比略小于 90%，优先保证能识别）；内容极长又把宽高设得很小时每模块不足 1 像素会扫不出，调大宽高即可。浅色块配深色底多数扫码器认不出，建议深色块配浅色底；本工具识别时会自动尝试反色一次。结果表格**双击一行复制该二维码图片**（可直接 Ctrl+V 到微信 / Word），也能在识别页「剪贴板粘贴」放回来识别。
- **清单解析**：Word 按每行一条（表格取每行首格）；Excel 读取所有非空单元格、按行优先、跳过表头（只读第一个工作表）；CSV / TSV 取每行第一个非空单元格；空行忽略。只用标准库，无需装 Office；旧版 `.xls` / `.doc` 需另存为新格式。
- **二维码 → 文本**：添加图片 / 文件夹 / 剪贴板粘贴 / 拖入；「包含子文件夹」默认勾选；一图多码全部读出。结果表格**双击一行单独复制该行识别内容**，也可一键复制全部，或导出 CSV / TXT / Excel / Word。Word / TXT 一行一条识别内容；CSV / Excel 为「文件名 / 识别结果」两列表格（不含序号、状态）。
- **记住上次设置**：上次导出位置、命名、前缀、起始序号、图片宽高、前景色、背景色、递归、导出格式、页签存到 `%APPDATA%\二维码工具\settings.json`（纯文本 JSON，删掉即恢复默认）；不记输入内容和识别结果。
- 生成 / 识别可取消，进度由右上角「处理中 x/y」文字显示；两个页面不设进度条。

验证

双击 `二维码工具.exe` 检查启动；改动源码后按开头命令重新打包。
